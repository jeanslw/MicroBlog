# MicroBlog 更新日志

## [1.3.0] - 2026-09-02

后台管理面板改版、站内全文搜索、RSS/Atom 订阅。

### 新增

- 后台全面改版：新增毛玻璃专属布局（`admin_base.html`），左侧粘性菜单（站点设置 / 文章与栏目 / 轮播图 / 修改密码 / 退出）+ 毛玻璃内容卡片。
- 新增后台首页 `/admin/panel`（默认展示站点设置）；登录后直接进入后台；站点设置表单抽取为共享 partial，首页与独立页面共用。
- 站内全文搜索（`/search`）：标题与正文关键词模糊匹配、分页、独立搜索结果页。
- RSS 2.0（`/rss`）与 Atom（`/feed`）订阅源（基于 `feedgen`），页面加入 RSS/Atom 自动发现 `<link>` 与页脚订阅图标；订阅时间使用 Asia/Shanghai 时区，Windows/精简镜像以 `tzdata` 兜底。
- 支持栏目重命名（文章通过 `category_id` 自动跟随）。
- Banner 上架/下架（`is_active`），并为存量数据库提供幂等的轻量迁移（`ALTER TABLE`）。

### 变更与修复

- 新页面（搜索/后台）的玻璃主题样式适配；主题切换脚本增强；样式缓存戳更新。
- 文章正文改为保存原文、读取展示时经 nh3 白名单净化（既防存储型 XSS，又保留排版）。
- `Banner` 模型新增 `is_active` 字段；MySQL `init.sql` 同步建表结构。
- 新增依赖：`feedgen==1.0.0`、`tzdata==2026.3`。

### 测试、文档与国际化

- 测试新增 `test_feed.py`，并扩充 auth/banner/blog 用例（累计 **约 200 项**测试函数）。
- i18n 词条大规模扩充（en +146 / zh +137 行），覆盖 RSS、搜索与后台管理相关术语。
- README、项目截图（含中英文后台面板截图）、`.dockerignore` 与忽略规则更新至 v1.3.0；末尾提交统一文档版本号。

## [1.2.0] - 2026-09-01

玻璃拟态 UI + 主题切换 + Python CI + 完整测试套件，在 v1.0.0 基线之上包含大量后台/博客功能与修复提交。

### 新增

- 全站玻璃拟态透明 UI（卡片、表格、导航栏、面包屑、管理页），并通过高优先级 CSS 覆盖系统性修复“白底/不透明”的玻璃失效问题。
- 5 套动态炫酷背景（极光 / 星空 / 流光 / 气泡 / 经典），右下角悬浮调色盘一键切换，选择记忆在 `localStorage`。
- 内置 12 张 1920×1080 高清背景图库；后台可上传图片或填写 URL 自定义背景。
- 主题切换脚本（`theme-switcher.js`）、鼠标光标粒子特效（`cursor-effect.js`）、Flash 消息升级为 Toast 提示（`flash-toast.js`）、语言切换下拉（`lang-toggle.js`）。
- 导航重构为下拉菜单：*文章管理*（草稿/新建/撤回）与*轮播图管理*（列表/新增/批量撤回）。
- 已发布文章管理页（`/article/manage`），支持编辑/撤回/删除；文章可撤回至草稿（`/article/recall`）；Banner 批量撤回（`/banner/withdraw_all`）。
- 支持删除栏目（其下文章自动归为“未分类”）。
- 编辑器支持 Markdown 文章文件一键导入（纯前端上传）。
- 后台增强：Logo 上传、背景图库管理、站点设置更丰富。

### 安全、修复与重构

- 点赞改为数据库端原子自增，并加 `UNIQUE(article_id, ip)` 约束。
- 草稿禁止匿名访问；登录 `next` 参数防开放重定向。
- 删除文章/更换图片时自动清理旧上传文件；GIF 保留动画帧；`favicon_path` 配置生效。
- 移除测试中硬编码的 `SECRET_KEY`（此前导致 CI 密钥扫描失败）。
- Docker 部署修复：compose 挂载 `static/uploads`、容器时区支持、`ProxyFix` 获取 nginx 后的真实客户端 IP。
- 通过 `.gitattributes` 将全项目行尾统一为 LF。
- 全量 `ruff format` 规范化；新增 pyright 类型检查配置。

### 测试与 CI/CD

- GitHub Actions CI：ruff + pytest 矩阵；`pip-audit` 安全扫描；Docker 镜像发布工作流；release 与 security 工作流；Dependabot 配置。
- 测试套件纳入版本控制并扩充至 **177 项**，覆盖认证/博客/评论/轮播/i18n/模型/安全/站点/工具/UI 主题/冒烟等模块。

### 文档与国际化

- 新增 `CONTRIBUTING` / `SECURITY` / `CODE_OF_CONDUCT` 中英文文档；README 更新至 v1.2.0 并更换截图。
- i18n 词条扩充（zh ≈143 / en ≈149）；清理过期 `messages.pot` 模板与仅开发用翻译辅助脚本。

## [1.0.0] - 2026-08-15

完整的首个正式版本，覆盖从首次提交到 ruff 规范化基线的全部内容。

### 新增

- 博客核心功能：文章发布与编辑（EasyMDE Markdown 编辑器）、代码高亮（Prism）、草稿/发布管理、文章详情页。
- 编辑器内图片上传，Pillow 自动压缩/缩放，nginx 防盗链配置。
- 文章评论与回复、按 IP 的点赞防刷；文章栏目（分类）管理、侧边栏分类筛选。
- Banner 轮播图及后台管理（增删改、排序、图片上传）。
- 管理后台：管理员登录、站点设置、修改密码、轮播图与文章管理。
- 中英双语国际化（Flask-Babel）：自动跟随浏览器语言，顶部下拉框手动切换。

### 架构与安全

- 迁移至 SQLAlchemy ORM，分层模块化（`models` / `forms` / `utils` / `database`，应用工厂 + Blueprint）。
- 安全加固：写操作全部 CSRF 保护、nh3 HTML 净化防存储型 XSS、登录防暴力破解（IP+用户名，5 次失败锁定 5 分钟）、安全 Session（HttpOnly/SameSite/Secure）、上传校验（MIME 白名单、UUID 命名、大小限制）、`SECRET_KEY` 走环境变量、DEBUG 默认关闭。
- 性能优化与查询逻辑改进。
- 统一错误处理，新增通用 `error.html` 错误页。

### 部署

- Docker 部署支持：生产 Dockerfile（python:3.11-slim + gunicorn、非 root、健康检查）、`docker-compose.yml`（web + db + nginx）、nginx 反代与静态资源直出、`.env.example` / `.env.docker.example` 模板。
- 双数据库支持：SQLite 开箱即用与 MySQL；WSGI 入口（`wsgi.py`）、gunicorn 与 uWSGI 配置。
- 完整的中英文部署文档与截图。
