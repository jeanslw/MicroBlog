# 更新日志

## v1.3.6 (2026-10-11)

- **新增**
  - 站点配置按用途拆分，附带幂等的启动迁移。
  - 数据库结构版本化：迁移可自动执行，也可从后台手动执行并查看记录。
  - 手动迁移模式：待迁移期间对外返回升级页，迁移完成后自动恢复。
  - 后台「迁移数据库」页面。
  - 日志级别可配置，日志按大小轮转并外挂到宿主机。
  - 轮播图变更时间与登录失败时间。
  - 程序版本低于数据库版本时拒绝启动，并提供临时放行开关。
  - 管理员手册（中英）与升级迁移章节。
- **修复**
  - 数据库备份兼容非 root 账号。
- **优化**
  - 清理无调用的代码。

- **新增**
  - Compose 启动前的环境预检。

  - 站点配置读写统一到同一行。
  - 过期限流记录自动清理。
  - 搜索关键词按字面匹配。

  - 「关于我」等外链拒绝伪协议。
  - 备份与恢复兼容新版数据库客户端。
  - 缺失的图片回落到内置占位图。
  - 移动端折叠菜单的搜索行布局。
  - 主题切换器恢复触摸可用。
  - 后台面包屑补齐所属分组。
  - 反向代理不再对外暴露版本号。
- **优化**
  - 数据库镜像升级到 8.4，存量账号可继续认证。
  - 清理无用配置项。
  - 工作流依赖锁定到固定版本，新增代码安全扫描。
  - 质量门禁加入类型检查、格式检查与依赖一致性校验。
  - 依赖漏洞扫描在主干与定时任务上阻断构建。
  - 升级存在已知漏洞的依赖。
